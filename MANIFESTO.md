# Project Manifesto

## 📢 Core Beliefs
1. **Simplicity over Complexity:** We strive for Wrap, do not fork (ComfyUI is called over REST — we never diverge from upstream).
2. **Speed and Safety:** Leveraging Rust, tonic, Python, ComfyUI, civitai API, Flux dev, SDXL, PyTorch to achieve Curated workflow templates over free-form prompts (character generation ships as versioned workflow.json).
3. **Open Collaboration:** Our mission is AI-only character image pipeline — given a persona spec from vtuber-commons, produce a rig-ready base image with zero manual ComfyUI clicking, backed by a community-safe civitai consumption ledger..

## 🎯 Our Aim
We build tools that empower developers to handle complex MLOps workflows with ease.
